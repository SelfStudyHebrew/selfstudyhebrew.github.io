Card Creator

Create Anki cards directly from Hebrew sentences

Quickly add new vocabulary to your Anki deck by creating cards from i+1 sentences with audio, context, and optional AI-powered translations.

Overview

The Card Creator allows you to instantly create Anki flashcards from Hebrew sentences you encounter while browsing. When you find an i+1 sentence (highlighted with a blue-tinted background), Shift+click on it to automatically create a flashcard with the sentence, unknown word, translation, and audio. You can also highlight any sentence and Shift+hover to bring up the dictionary and create a flashcard that way.

One-Click Creation

Shift+click any i+1 sentence to instantly create an Anki card with all fields populated

Audio Recording

Automatically captures audio from video subtitles for native pronunciation context

Optional AI Translation

Claude AI provides accurate, context-aware translations of sentences and words

Image Search

Search Wikimedia Commons and Openverse for an image to attach to the card — no API key required

AI Image Generation

Generate images with Cloudflare Workers AI (free) or Gemini (paid) directly from the card creator

Audio Trimming

Trim recorded subtitle audio with a drag-handle waveform editor — preview the selection before applying

How to Create Cards

1

Find an i+1 Sentence

Look for sentences with a blue-tinted background highlight. These sentences contain exactly one unknown word, making them perfect for vocabulary acquisition.

Tip: You can also create cards from potentially-i+1 sentences (purple-tinted highlight) which contain one potentially-known word with a prefix and 0-1 unknown words.
2

Shift+Click the Sentence

Hold down the Shift key and click anywhere on the highlighted sentence. A card creation dialog will appear.

Tip: If you're watching a video, it will automatically pause when the card creator opens and resume when you close it — so you won't lose your place.
3

Review the Card Details

The dialog shows:

  • Target Anki Deck - The deck which the sentence will be added to, and the note type being used. Defaults can be set in Settings
  • Hebrew Sentence - The full sentence
  • Audio field - If subtitle audio was recorded, the Audio field is pre-filled with the filename and shows ▶ Play and ✂ Trim buttons. Click ▶ Play to preview the audio, or ✂ Trim to open the waveform editor:
    • Drag the left/right handles on the waveform to set start and end trim points
    • Click ▶ Test to preview just the selected region (click again to stop)
    • Click ✂ Apply Trim to encode and save the trimmed audio to Anki
  • Translate Button - If you have Claude configured it will use it to translate the sentence and output the result in the field next to the button
  • Define Button - If you have Claude configured it will use it to define each unknown word in the context of the sentence
  • Image field - Find or generate an image to attach to the card. Three source tabs are available:
    • All / Wikimedia / Openverse — search free image libraries. The search box is pre-filled with the unknown word(s). Click any result to store it in Anki.
    • ✨ Generate — AI image generation. Choose a provider (Cloudflare free or Gemini paid), edit the prompt if needed, and click Generate. The image is stored in Anki automatically.

You can edit any field before creating the card.

4

Create the Card

Click "Create Card" to add it to your Anki deck. The card is immediately available in Anki for review.

Troubleshooting

Shift+click doesn't work

  • If this is not a subtitle, Shift+clicking only works on highlighted sentences (blue-tinted for i+1, purple-tinted for potentially-i+1)
  • Verify AnkiConnect is running (check extension popup)
  • Try clicking directly on the highlighted text, not nearby
  • Refresh the page and try again

Card created but missing translation

  • Check that Claude API key is configured in settings
  • Verify you have API credits available at console.anthropic.com
  • Check browser console for API errors

Audio not recording

  • Make sure the video is playing or has played recently
  • Check browser audio permissions
  • Try playing the video for a few seconds before creating the card
  • Some sites may block audio capture - cards will still be created without audio
