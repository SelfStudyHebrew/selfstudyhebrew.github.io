🤖 i+1 Sentence Generator

AI-powered personalized Hebrew sentences

Generate custom i+1 sentences using your known vocabulary and AI. Perfect for focused vocabulary acquisition when you can't find natural content at your level.

Overview

The i+1 Sentence Generator uses Claude AI to create personalized Hebrew sentences that contain exactly one unknown word, sorted by frequency.

How to Use the Generator

1

Open the Sentence Generator

Click the extension icon in your toolbar, then click the "Sentence Generator" button in the popup.

⚡ Requirement: You must have Claude API configured in settings to use this feature. See the Setup Guide for instructions.
2

Select Number of Words/Sentences

Choose how many words you want to learn and how many sentences to generate per word.

Click "Start Generation"

3

Review Your Vocabulary

The generator first shows you a list of words to review. These are the highest frequency words that you do not currently know. For each word:

  • Untick if you know it - This will mark it as known

Click "Generate Sentences to replace any unticked words with new words. Then rinse and repeat until all the words present are unknown.

4

Generate Sentences

Click "Generate Sentences" and wait 10-20 seconds. Claude AI will create personalized sentences using:

  • Your known vocabulary (from Anki)
  • One target word per sentence
  • Natural, conversational Hebrew
5

Review and Create Cards From Sentences

Review the generated sentences. Each sentence shows:

  • Hebrew sentence - With the target word highlighted
  • Clipboard button - To copy the sentence to your clipboard
  • Reverse button - To open the sentene in Reverso
  • Card button - To send the sentence to the card creator

How It Works

Vocabulary Context

The generator sends your vocabulary list to Claude AI (up to 3000 words by default).

Claude uses this context to ensure generated sentences only use words you know, plus exactly one new target word.

Quality Assurance

Claude AI is specifically prompted to:

  • Use natural, conversational Hebrew
  • Create sentences that make sense in real contexts
  • Vary sentence structure and topics
  • Ensure the target word is essential to the sentence meaning

Cost & Usage

Rough Costs

With default settings (3000 words context):

  • Per session (5 words, 3 sentences each): ~$0.05
  • Per word: ~$0.01 first request, ~$0.001 cached
  • Monthly (daily use, 5 words/day): ~$1.50/month
  • Yearly: ~$17/year for daily practice

Reducing Costs

To minimize API costs:

  • Generate in batches - Generate for 5-10 words at once to leverage caching. 10 words in one day is cheaper than 10 over 2 days.
  • Reduce vocabulary size - Configure max words in settings (default: 3000)
  • Use natural content first - Reserve generator for targeted vocabulary gaps
  • Set API spending limits - At console.anthropic.com/settings/limits
⚠️ Important: Always set spending limits on your Claude API account to prevent unexpected charges.

Troubleshooting

Generator button is disabled

  • Make sure you have Claude API key configured in settings
  • Verify you have API credits at console.anthropic.com
  • Check that AnkiConnect shows "Connected"

Generation fails with error

  • Check API key is correct in settings
  • Verify spending limits aren't reached
  • Check browser console for detailed error messages
  • Report the error
