i+1 Sentence Generator

AI-powered personalized Hebrew sentences

Generate custom i+1 sentences using your known vocabulary and AI. Perfect for focused vocabulary acquisition when you can't find natural content at your level.

Overview

The i+1 Sentence Generator uses Claude AI to create personalized Hebrew sentences that contain exactly one unknown word, sorted by frequency.

How to Use the Generator

1

Open the Sentence Generator

Click the extension icon in your toolbar, then click the "Generate i+1 Sentences" button in the popup.

Requirement: You must have Claude API configured in settings to use this feature. See the Setup Guide for instructions.
2

Select Number of Words/Sentences

Choose how many words you want to learn and how many sentences to generate per word.

Click "Start Generation"

3

Review Your Vocabulary

The generator first shows you a list of words to review. These are the highest frequency words that you do not currently know. For each word:

  • Untick if you know it - This will mark it as known
  • "likely a name" - Words that are mostly used as names (for example אלי, which is usually the name Eli) are flagged next to their rank and unticked by default. Tick one if you do want sentences for it.

Click "Generate Sentences" to replace any unticked words with new words. Repeat until every word in the list is one you don't know, then click "Generate Sentences" once more to start generating.

4

Generate Sentences

Click "Generate Sentences" and give it a little while — every sentence is checked and proofread before it is shown. Claude AI will create personalized sentences using:

  • Your known vocabulary (from Anki)
  • One target word per sentence
  • Natural, conversational Hebrew
5

Review and Create Cards From Sentences

Review the generated sentences. Each sentence shows:

  • Hebrew sentence - With the target word highlighted
  • Clipboard button - To copy the sentence to your clipboard
  • Reverso button - To open the sentence in Reverso
  • Card button - To send the sentence to the card creator

Below the results:

  • Export to File - Download all generated words and sentences as a JSON file
  • Generate More - Go back to the start screen to generate another batch

Your last batch is saved — next time you open the generator, click Load Previous Results to pick up where you left off.

How It Works

Vocabulary Context

The generator sends your vocabulary list to Claude AI (up to 3000 words by default, configurable in settings). Claude uses this context to ensure generated sentences only use words you know, plus exactly one new target word.

Quality Assurance

Claude AI is prompted to use natural, conversational Hebrew; create sentences that make sense in real contexts; vary sentence structure and topics; and ensure the target word is essential to the sentence meaning.

Every sentence goes through two checks before you see it:

  • Vocabulary check — using the same rules as the word highlighter, every word except the target must be a word you know. A known word may also appear with a single ו, ל, ב or ש prefix, with the definite article ה (also after ו or ש, as in שהבית), or in its regular plural or feminine form (for example סוגים from סוג, or חברה from חבר). Irregular forms such as בתים are not recognised.
  • Grammar and meaning check — a second Claude call proofreads the sentences that passed the vocabulary check and drops any with agreement or definiteness errors (for example "בגדים שונות"), unnatural wording, or illogical meaning.

Sentences that fail are rejected and Claude is asked again (up to three attempts per word). If a word still has too few verified sentences, the closest ones are shown with an amber "Not verified" note listing the extra words they contain; these also go through the grammar and meaning check.

The word list skips forms that are just a known word plus a common prefix or plural/feminine ending (for example הבית when you already have בית), and flags words that are mostly names, so you are offered genuinely new vocabulary.

Custom Prompts

All three Claude prompts are fully editable in Settings → AI Integration:

  • Sentence Generation Prompt — the prompt used for each target word. Supports {{TARGET_WORD}} and {{COUNT}} placeholders.
  • AI Define Prompt — the prompt used when you click Define in the card creator. Supports {{SENTENCE}} and {{WORD}} placeholders.
  • AI Translate Prompt — the prompt used when you click Translate in the card creator. Supports {{SENTENCE}} and {{CONTEXT}} placeholders.

Each prompt has a "Reset to Default" button to restore the original if needed.

Cost & Usage

Cost Tracking

The extension tracks the cost of every Claude API call and shows a running total in Settings → AI Integration. Below the total, a per-feature breakdown shows how much you've spent on each type: Subtitle Translations, Sentence Translations, Word Definitions, and Sentence Generation. Costs are calculated from the token usage returned by the API, using Anthropic's published per-model rates.

You can reset the total and breakdown at any time from the settings page.

Reducing Costs

  • Expect roughly 2 cents per word — the retries and the proofreading check add a few calls per word, but each is small.
  • Generate in batches — generating for 5–10 words in one session is cheaper than spreading them across days, because the known-words list is sent as a cached prompt block.
  • Reduce vocabulary size — lower the "Max Words for i+1 Generation" setting (default: 3000) to reduce tokens sent per call.
  • Use natural content first — reserve the generator for targeted vocabulary gaps rather than as your primary input.
  • Set API spending limits — at platform.claude.com/settings/limits.
Important: Always set spending limits on your Claude API account to prevent unexpected charges.

Troubleshooting

Generator button is disabled

  • Make sure you have Claude API key configured in settings
  • Verify you have API credits at platform.claude.com
  • Check that AnkiConnect shows "Connected"

Generation fails with error

  • Check API key is correct in settings
  • Verify spending limits aren't reached
  • Check browser console for detailed error messages
  • Report the error
