What is SelfStudyHebrew?

SelfStudyHebrew is a browser extension that connects to Anki and highlights Hebrew words across the web based on your learning progress. It helps you learn Hebrew through comprehensible input by showing you exactly which words you know, which you're learning, and which are new.

🎯 Smart Highlighting

Words are color-coded based on your Anki progress: mature (green), learning (orange), and unknown (red).

📚 i+1 Detection

Automatically highlights sentences with exactly one unknown word—the perfect learning zone.

📖 Dictionary Lookup

Shift+hover any Hebrew word for instant definitions, frequency rankings, and verb conjugations.

🎬 Video Subtitles

Watch Hebrew content on YouTube and Netflix with highlighted subtitles and comprehension tracking.

🃏 Anki Integration

Create flashcards directly from sentences with optional AI-powered translations.

🤖 AI Sentence Generator

Generate personalized i+1 sentences using words you know to learn new vocabulary in context.

Prerequisites

1. Anki Desktop Application

You need Anki installed and running on your computer.

Download Anki

2. AnkiConnect Add-on

This add-on allows the extension to communicate with Anki.

  1. Open Anki
  2. Go to Tools → Add-ons → Get Add-ons
  3. Enter code: 2055492159
  4. Click OK and restart Anki
More Info

3. Firefox Browser (or Chrome)

Currently optimized for Firefox. Chrome support coming soon!

Installation

For Firefox (Temporary Installation)

  1. Download or clone the extension repository
  2. Open Firefox and navigate to about:debugging
  3. Click "This Firefox" in the left sidebar
  4. Click "Load Temporary Add-on"
  5. Navigate to the extension directory and select manifest.json
⚠️ Note: Temporary add-ons are removed when Firefox closes. For permanent installation, the extension needs to be signed through Firefox Add-ons Developer Hub or installed as a self-distributed extension.

For Chrome (Coming Soon)

ℹ️ Chrome Support: Chrome version is in development. The extension is 95% compatible and will be available on the Chrome Web Store soon.

Initial Setup

Step 1: Configure Anki Field Name

  1. Click the extension icon in your browser toolbar
  2. Click "Settings"
  3. Set the Anki Field Name to match your Hebrew field (default: "Hebrew")
  4. Optionally, set a Deck Filter to limit to specific decks
  5. Click "Save Settings"

Step 2: Load Your Hebrew Words

  1. Make sure Anki is running
  2. In the extension popup, check that AnkiConnect shows "Connected"
  3. Click "Refresh Words" to load your vocabulary from Anki
  4. You should see your word counts appear (Mature, Learning, Total)

Step 3: Test It Out!

  1. Navigate to any Hebrew website or article
  2. You should see Hebrew words highlighted based on your knowledge
  3. Shift+hover over any word to see dictionary definitions
  4. Look for light blue highlighted sentences (i+1 sentences)
💡 Tip: Try watching a YouTube video with Hebrew subtitles! Click the "📖 Hebrew Subs" button that appears to see highlighted subtitles and comprehension statistics.

Key Features

Word Highlighting

Every Hebrew word on any webpage is automatically highlighted based on your Anki progress. Words are categorized as mature (≥21 days interval), learning (<21 days), or unknown.

i+1 Sentence Detection

The extension highlights sentences with exactly one unknown Hebrew word (ignoring non-Hebrew text). This is the optimal difficulty level for language acquisition—challenging but comprehensible.

Dictionary Popup

Shift+hover any Hebrew word to see:

  • Definitions from multiple Hebrew-English dictionaries
  • Word frequency ranking (how common the word is)
  • Verb conjugation patterns (binyanim)
  • Custom definitions you've added
  • Option to mark word as "already known"

Video Subtitle Support

Works with YouTube and Netflix Hebrew subtitles:

  • Subtitles appear with word-level highlighting
  • Subtitle browser shows all subtitles with timestamps
  • Real-time comprehension percentage
  • i+1 sentence detection in subtitles
  • Keyboard navigation (← → ↓ keys to jump between subtitles)

Anki Card Creation

Create flashcards directly from highlighted sentences. The extension can optionally use Claude AI to generate translations and definitions for unknown words.

i+1 Sentence Generator

Generate personalized Hebrew sentences that contain exactly one unknown word, using only words you already know. Perfect for targeted vocabulary acquisition in context.

  • Uses frequency-ranked unknown words
  • All other words in sentences are from your known vocabulary
  • Configurable number of words and sentences
  • Copy sentences, translate on Reverso, or create Anki cards directly

Optional: AI Features

SelfStudyHebrew can use Claude AI for enhanced features like translations, definitions, and sentence generation. This is completely optional—the core features work without it.

Setting Up Claude API

  1. Get an API key from console.anthropic.com
  2. Open extension settings
  3. Enter your API key in the "Claude API Key" field
  4. Important: Set spending limits at console.anthropic.com/settings/limits
  5. Save settings
⚠️ Cost Control: The i+1 sentence generator uses Claude's prompt caching feature to minimize costs. At default settings (3000 words), expect ~$0.05 per generation session (5 words), or ~$17/year for daily use. Always set spending limits in your Anthropic account!
💡 Cost Optimization: You can adjust "Max Words for i+1 Generation" in settings to balance between cost (lower = cheaper) and sentence variety (higher = more variety). The system uses smart sampling: 50% most frequent words + 50% random words for optimal results.

Tips & Best Practices

📚 For Effective Learning

  • Focus on i+1 sentences—they're your optimal learning zone
  • Use the sentence generator to create targeted study material
  • Watch Hebrew videos with subtitles to practice listening and reading together
  • Mark words as "already known" when you recognize them outside of Anki

⚙️ Performance Tips

  • Refresh your word list periodically (especially after Anki study sessions)
  • The extension caches dictionary data and word lists for better performance
  • Use "Strip Nikud" option if you prefer reading without vowel marks
  • Set a deck filter if you only want to track specific Anki decks

🎬 Video Learning Tips

  • Use arrow keys to navigate between subtitles (← previous, → next, ↓ repeat)
  • The subtitle browser shows all subtitles with comprehension stats
  • Create Anki cards directly from interesting subtitle sentences
  • Watch the same content multiple times to track your progress

💾 Data Management

  • Export custom definitions regularly (auto-export option available)
  • Export your known words list for backup
  • Bulk import words to the "AlreadyKnown" deck for words you recognize

Troubleshooting

AnkiConnect shows "Disconnected"

  • Make sure Anki is running
  • Verify AnkiConnect is installed (code: 2055492159)
  • Check that AnkiConnect is listening on port 8765 (default)
  • Try restarting Anki

Words not highlighting

  • Check that "Enable Highlighting" is turned on in the popup
  • Verify your "Anki Field Name" matches your cards
  • Click "Refresh Words" to reload from Anki
  • Make sure you're on a page with Hebrew text

YouTube subtitles not working

  • Make sure the video has Hebrew subtitles available
  • Try refreshing the page
  • Check browser console for errors (F12)
  • Disable VPN if you're getting anti-bot warnings

i+1 Generator errors

  • Verify your Claude API key is correct
  • Check you haven't exceeded your API spending limit
  • Make sure you have known words loaded from Anki
  • Try reducing "Max Words for i+1 Generation" if you get timeouts
